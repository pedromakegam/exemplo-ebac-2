# Programação e algoritmo

Na programação procedural, o programa é organizado em procedimentos que recebem dados e executam etapas. Por exemplo: ler os dados de um produto, calcular seu preço e mostrar o resultado.

Na programação orientada a objetos, dados e comportamentos relacionados ficam reunidos em objetos. Um Produto pode guardar nome e preço, enquanto uma Venda reúne os itens e calcula o total. O encapsulamento ajuda a controlar como esses dados são alterados. Herança permite especializar um tipo, e polimorfismo permite usar implementações diferentes por um contrato comum.

As duas formas podem resolver o mesmo problema. A diferença está principalmente na organização das responsabilidades. Java utiliza classes e objetos, mas um método também pode executar uma sequência procedural de instruções.
