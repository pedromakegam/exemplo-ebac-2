# Aplicação JSF implantada no Tomcat

Tomcat 10.1.60, Java 17 e PostgreSQL 16. O WAR cadastro-jsf foi implantado em webapps e acessado em http://127.0.0.1:18089/cadastro-jsf/. Cadastro realizado pelo formulário.

O botão Editar carregou os dados no formulário. Após salvar, a tabela exibiu o nome atualizado no mesmo registro.

O botão Excluir removeu o registro de teste. A aplicação confirmou a operação e a lista ficou vazia.

As capturas estão em respostas.pdf. Código completo no módulo 38. O Tomcat foi baixado do site oficial da Apache e o SHA-512 foi conferido. O servidor foi limitado a 127.0.0.1.
