# Fábrica de carros

Abstract Factory cria famílias de produtos: carro e motor elétricos ou a combustão. A aplicação depende dos contratos da fábrica e dos produtos.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl mod15 -am test
```

Para executar a demonstração depois de compilar:

```sh
java -cp mod15/target/classes br.com.pedro.ebac.ExemploFabrica
```
