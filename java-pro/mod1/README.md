# Estruturas de dados

Pilha com vetor redimensionável, fila com nós e lista simplesmente encadeada. Nenhuma das três usa uma coleção pronta para armazenar seus elementos. Índices da lista começam em zero.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl java-pro/mod1 -am test
```
