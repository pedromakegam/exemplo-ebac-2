# Calculadora, Fibonacci e documentação

Testes das quatro operações, divisão por zero e Fibonacci com casos base e valores conhecidos. Para gerar a documentação: `mvn -pl java-pro/mod5 javadoc:javadoc`.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl java-pro/mod5 -am test
```
