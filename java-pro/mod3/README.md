# Backtracking e algoritmo guloso

Gera os subconjuntos de tamanho k e calcula troco usando moedas 5, 2 e 1.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl java-pro/mod3 -am test
```

Para executar a demonstração depois de compilar:

```sh
java -cp java-pro/mod3/target/classes br.com.pedro.ebac.CombinacoesETroco
```
