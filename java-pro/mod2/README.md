# Recursão e programação dinâmica

Fatorial recursivo, top-down e bottom-up com BigInteger. Fibonacci ingênuo e dinâmico para comparação.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl java-pro/mod2 -am test
```

Para executar a demonstração depois de compilar:

```sh
java -cp java-pro/mod2/target/classes br.com.pedro.ebac.Algoritmos
```
