# PrimeiroProjeto

PrimeiraClasse imprime a saudação solicitada.

Requer JDK 17 e Maven. Execute a partir da raiz do repositório:

```sh
mvn -pl mod5 -am test
```

Para executar a demonstração depois de compilar:

```sh
java -Dfile.encoding=UTF-8 -cp mod5/target/classes br.com.pedro.ebac.PrimeiraClasse
```
